Commissioned project / interactive literary atlas / 2026

FJM Atlas /
Interactive Map

For the exhibition Manuscrit trouvé à Saragosse | enquête sur un roman-monde, the atlas turns the geography of Jean Potocki’s novel into a tactile editorial interface: visitors move between places, stories and sources while keeping the feeling of one continuous literary investigation.

Status commissioned / in development / not yet deliveredRole interaction design / software architecture / development / map integrationSystem Electron / TypeScript / OpenSeadragon / offline runtime
01

Context + brief

Make a “novel-world” explorable without reducing it to a conventional map.

The exhibition follows the literary investigation behind Jean Potocki’s Manuscrit trouvé à Saragosse and the circulation of its nested stories across places and periods. The requested atlas has to help visitors explore those locations and their links to stories and characters while preserving continuity, reading and the documentary character of the exhibition.

02

Response

A museum interface built around the map, not around menus.

I designed and developed the atlas as a dedicated offline kiosk application. The map remains the primary object; touch navigation, location selection, editorial reading and passive exhibition behaviour are treated as one continuous system rather than separate screens.

high-resolution map→touch navigation→interactive places→editorial cartels→related locations→offline kiosk

Electron / TypeScript / OpenSeadragon / tiled map pipeline / touch pan + pinch + double-tap / structured editorial content / attract mode / idle reset / kiosk packaging / telemetry + remote maintenance

03

Interface

From world map to editorial reading.

A location selection keeps the map in view while opening its editorial material. The interface is designed so exploration can move between geography, text and related places without breaking the visitor’s spatial context.

04

Interaction

A map that behaves like an exhibition interface.

The map remains the main object. Touch targets, zoom, pan, location selection and editorial panels are designed to preserve spatial context instead of turning the experience into a conventional website. Opening a location keeps the map state visible; after inactivity, the kiosk can return to a neutral invitation state.

System architecture

Cartography, interaction
and content stay separate.

map source→tile pyramid→touch viewer→location state→editorial content→kiosk reset

The current prototype is an offline Electron application built around a high-resolution tiled map and structured location data. Cartography, interaction logic and editorial content are decoupled so the map, gestures and texts can evolve without rebuilding the whole interface.

Touch-first UX / high-resolution tiled media / offline kiosk logic / structured editorial pipeline / interaction tuning / performance testing

05

Current state

Commissioned and actively developed.

The project is currently under development for Fondation Jan Michalski and has not yet been delivered. This DEV portfolio page is being prepared while the software, interaction details and final installation qualification are still evolving.
