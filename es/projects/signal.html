Simulación / I+D / 2026

SIGNAL
Sistema espacial

Una simulación técnica de un sistema de interacción espacial donde el movimiento humano se convierte en datos en tiempo real y después en comportamiento distribuido sobre superficies LED.

Estado solo simulación / no instaladoRol diseño de sistema / simulador / arquitectura en tiempo realHerramientas Godot / GDScript / mmWave / WebSocket / TouchDesigner / Art-Net
A

Idea del sistema

El movimiento se convierte en señal.

El sistema se concibe alrededor de personas que se mueven por una zona física. Las observaciones de radar describen posición y movimiento sin depender de una imagen de cámara. Estas medidas se convierten en un estado compartido en tiempo real capaz de influir texto, movimiento, intensidad y otros comportamientos en varias salidas.

Legible a dos niveles

Para un visitante la idea es simple: el movimiento modifica el entorno. Técnicamente, el proyecto es un pipeline distribuido de captación, red y renderizado en tiempo real.

B

Capa de simulación

Godot como herramienta de diseño.

El proyecto actual es un simulador, no la documentación de una obra instalada. Modela personas, cobertura de sensores, sectores espaciales y superficies LED distribuidas para probar la lógica de interacción antes del despliegue de hardware.

Lo que ya puede probarse

Movimiento multiobjetivo, zonas de detección solapadas, influencia de pantallas, estados de multitud, paquetes de red, configuraciones de proyecto y rendimiento runtime pueden explorarse dentro de la simulación.

C

Pipeline objetivo en tiempo real

SENSORES

Radar mmWave

Varios módulos de tracking de 24 GHz proporcionan observaciones de posición y movimiento al ritmo de los sensores.

EDGE / RED

Objetivo ESP32 + Ethernet

Se prevé un bridge de red para recopilar datos de sensores y exponer un flujo estable. El hardware exacto sigue formando parte de la fase de implementación.

DATOS

WebSocket / JSON

El simulador ya define un contrato de red que separa observaciones brutas, tracks espaciales y estados de salida.

TIEMPO REAL

TouchDesigner

TouchDesigner sigue siendo la capa final prevista para comportamiento, renderizado, mapping y monitorización del sistema.

SALIDA

Art-Net / LED

La salida objetivo es un conjunto de superficies LED distribuidas, direccionadas mediante una etapa final de pixel mapping y Art-Net.

D

Estado actual

Primero la simulación.

Aquí no se afirma ninguna instalación física. El valor actual de SIGNAL está en el modelo de sistema: lógica de interacción, hipótesis de captación, arquitectura de datos, visualización y pruebas de rendimiento se desarrollan antes de una posible implementación in situ.

Estado en portfolio

I+D / simulación técnica. Los datos de cliente, lugar y despliegue se omiten intencionadamente.
